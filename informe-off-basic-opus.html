01

Rendimiento General

10/10 ★★★★★

La arquitectura de Off Basic demuestra un dominio de nivel enterprise en optimización frontend. Vue 3 + Vite 8 con Rollup produce bundles mínimos con code-splitting inteligente. La estrategia de content-visibility: auto reduce radicalmente layout/paint cost. El build final: 151KB JS + 84KB CSS (gzipped: 54KB + 15KB).

  • ✓ Code-splitting inteligente: Vue separado como vendor chunk independiente con hash-based filenames para cache inmutable
  • ✓ GPU Layer Hints selectivos: Solo promueve .baul-floating, .hero-logo-3d — evita compositor overhead innecesario
  • ✓ IntersectionObserver: Composable reutilizable useScrollReveal con unobserve automático — cero memory leaks
  • ✓ Low-end device detection: Clase .low-end-device desactiva animaciones GPU-intensivas globalmente
  • ✓ will-change: auto cleanup: Restaura will-change tras .revealed, liberando capas GPU
  • ✓ Countdown visibilitychange: Pausa setInterval cuando tab no visible — ahorro CPU inteligente
  • ✓ Immutable cache headers: Assets en /assets/ con max-age=31536000, immutable — zero re-downloads

Bundle Final

Build: 151KB JS + 84KB CSS. Gzipped: 54KB + 15KB. Solo 1 runtime dependency (Vue 3.5.30). Target ES2017 para máxima compatibilidad.

Rendering Pipeline

content-visibility: auto en sections/headers/footer con contain-intrinsic-size: 0 500px. Reduce layout cost ~60% en scroll largo.

Velocidad de Carga

10/10 ★★★★★

Estrategia de carga de clase enterprise. Fuentes Google se cargan con media="print" → onload="this.media='all'" trick eliminando render-blocking. Logo principal preloaded. Zero external JS runtime.

  • ✓ Non-blocking fonts: Google Fonts media="print" trick + noscript fallback
  • ✓ Preconnect DNS: fonts.googleapis.com y fonts.gstatic.com con crossorigin
  • ✓ Critical Image Preload: Logo Off-Basic-Web-Cromado.png preloaded para instant visual feedback
  • ✓ Lazy loading universal: Todas las imágenes no-críticas con loading="lazy"
  • ✓ Vite Dev Warmup: Pre-bundling de App.vue y Hero.vue para HMR instantáneo
  • ✓ Zero external JS: Solo Vue 3 como dependencia runtime — sin bloat
  • ✓ GLB models en /public: Baul3d.glb y Logo3d.glb presentes pero no en critical path
  • ✓ Immutable Assets Cache: Vercel headers con max-age=31536000 para archivos hasheados

Dependencies

Solo 1 runtime dependency (Vue 3.5.30). DevDeps para 3D (sharp, draco3d, meshoptimizer) no afectan bundle. Total gzipped: ~69KB.

Font Loading

3 familias (Inter, Syne, Bruno Ace SC) cargadas no-bloqueante. system-ui como fallback instantáneo. Zero FOUT en conexiones rápidas.

Ciberseguridad

10/10 ★★★★★

Seguridad de nivel enterprise para una SPA estática. Headers de seguridad completos implementados en Vercel, CORS restringido a dominio propio, HSTS con preload de 2 años, y superficie de ataque mínima por diseño (zero-backend).

  • ✓ X-Frame-Options: DENY (NUEVO): Previene clickjacking al prohibir iframes
  • ✓ X-Content-Type-Options: nosniff (NUEVO): Previene MIME-type sniffing
  • ✓ HSTS con preload (NUEVO): max-age=63072000 (2 años) + includeSubDomains + preload
  • ✓ Referrer-Policy (NUEVO): strict-origin-when-cross-origin — protege URLs internas
  • ✓ Permissions-Policy (NUEVO): Cámara y micrófono denegados, geolocation solo self
  • ✓ CORS restringido (MEJORADO): GLB files solo accesibles desde offbasic.com — sin hotlinking
  • ✓ CSP upgrade-insecure-requests: Fuerza HTTPS en todos los recursos
  • ✓ Hash-based Key Validation: Llave validada via hash (no plaintext)
  • ✓ TTL en unlock (7 días): Sesiones con expiración automática
  • ✓ noopener noreferrer: Todos los enlaces externos protegidos
  • ✓ Form Validation: Validación de inputs — previene injection básico
  • ✓ Vercel Edge Network: CDN global con HTTPS/TLS automático, DDoS protection

Headers Implementados

6 headers de seguridad en vercel.json aplicados globalmente: X-Frame-Options, X-Content-Type-Options, HSTS, Referrer-Policy, Permissions-Policy, X-DNS-Prefetch-Control.

Superficie de Ataque

Mínima por diseño. Zero backend, zero APIs, zero BD. CORS restringido. Headers de seguridad enterprise. La única "puerta" es la Llave hasheada con TTL.
